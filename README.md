# animationsx-registry

Storage repo for [AnimationsX](https://github.com/youssefahmed2017) published CSS animations.

Each published animation is a single `.css` file under `animations/<slug>.css`, served instantly worldwide via jsDelivr:

```
https://cdn.jsdelivr.net/gh/youssefahmed2017/animationsx-registry@main/animations/<slug>.css
```

Files here are written by the AnimationsX app's publish flow (via the GitHub API) — do not edit directly.
